---
name: create-task
description: Create and scaffold a live-coding exercise, including importing a supplied task brief or Task Package. Use when the user wants an actual task rather than ideas only.
---

For an unspecified exercise, use `codex/codex_create_task.md` and `npm run task:design-context` to choose it.
For a provided brief/package, preserve its requirements and avoid unnecessary brainstorming. Report genuinely missing or conflicting requirements before scaffolding. Imported solution or question/session material must not enter the starter.
Read `docs/contracts/task.md` and `codex/codex_task_scaffold.md`; read taxonomy only as needed. Materialize files directly; no mandatory temporary hand-off package or chat copy step.
Create the smallest useful starter, run `scaffold:init` for snapshots/hashes, then `finalize:tasks`. Do not solve the exercise.
Finish with the task link, difficulty, target skill, useful run/preview command, and validation result. Keep evaluation-only content private.
