# Task contract

Directory: `tasks/<category>/<stable-slug>/`. Required files: `task.md`, `interviewer.md`, `main.ts` or `main.tsx`, the matching `main.scaffold.*`, and `scaffold.json`. Additional candidate-editable TypeScript files need matching snapshots and manifest entries.

## task.md

YAML frontmatter:

```yaml
---
title: "Exercise title"
category: async
taskType: fix-bug
difficulty: medium
problemShape: stale-async-response
interviewFocus: "Correct results when requests finish out of order"
reviewFocus:
  - correctness
  - async-safety
topics:
  - stale-responses
# UI tasks only:
# hasPreview: true
# previewEntry: main.tsx
---
```

Use categories and taskTypes from `TASK_TAXONOMY.md`. Topics use canonical IDs from `data/topic-catalog.json`; a new topic may be added for custom exercises. `scaffold:init` adds an ISO UTC `createdAt` if absent.

Body: one title and `## Context`, `## Goal`, `## Requirements`, `## Acceptance Criteria`. Constraints and non-goals are optional. Define relevant ordering, mutation, failure, timing, and boundary behavior explicitly without prescribing the intended implementation.

## interviewer.md

Plain English Markdown with `## Expected behavior`, `## Important cases`, `## Review focus`. Keep it short, observable, and consistent with the brief. It contains evaluation criteria, not questions, a full solution, or a session plan. No hidden follow-ups by default; user-requested extensions are handled explicitly as a change to the brief and criteria.

## scaffold.json

Generated by `npm run scaffold:init -- <task-path> [working-files...]`:

```json
{"schemaVersion":1,"files":[{"working":"main.ts","snapshot":"main.scaffold.ts","sha256":"<computed SHA-256>"}]}
```

Snapshots are exact initial copies, excluded from normal checks. The manifest covers every candidate-editable starter file, including test/support files. Paths must be unique, task-local, and not resolve outside the directory through symlinks. A task has exactly one main entry. UI preview entries must be manifest working TSX files exporting a default component.

## Imports

A supplied brief or Task Package may provide task and evaluation artifacts. Preserve its requirements and difficulty, normalize metadata to this contract, and ask only about blocking omissions/conflicts. Do not import old question logs, session state, or full solutions as starter code. No temporary package is required for direct Codex creation.

After task changes, run `npm run finalize:tasks`.
